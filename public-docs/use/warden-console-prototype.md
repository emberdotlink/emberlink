# Warden Console Prototype

The Warden Console prototype is a static mock of the operator dashboard
direction. It is meant to make the authority model visible: decisions waiting,
live leases, receipts, audit, setup, and future team posture.

[Open the Warden Console prototype](../prototypes/warden-console/)

This is not the shipped v0.3.0 dashboard behavior. It does not talk to
`emberd`, it does not read local state, and every value in it is fictional.
Use it to understand the intended shape of the product, not to validate your
local install.

The public static source is exported with the docs corpus at
`public-docs/prototypes/warden-console/index.html`.
