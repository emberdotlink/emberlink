# Emberlink Docs

Emberlink is the **Grant Warden for AI agents**. It keeps credentials in the
local daemon, turns authority into grants, and emits signed receipts so agent
actions remain auditable and revocable.

This public docs site has two lanes:

- **Use Ember** — install, onboard, launch, audit, and troubleshoot
- **Build with Emberlink** — core concepts, MCP, and integration surfaces

If you are evaluating Emberlink today, start here:
