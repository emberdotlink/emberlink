# emberlink

**Programmable trust between humans and machines.**

Emberlink is a local-first protocol for scoped, time-bound, revocable delegation of authority. Share credentials with friends and AI agents — without sharing the actual secret.

## Crates

| Crate | Description |
|---|---|
| `emberlink-cli` | Command-line interface |
| `emberlink-agent` | Agent authorization runtime (stdio JSON-lines protocol) |
| `emberlink-relay` | Relay daemon for async credential delivery |
