# Publishing


This repository is a curated downstream of an active development monorepo.

PRs are welcome, subject to maintainer review. Any change that touches code
also requires a security review.

All accepted contributions are cherry-picked through the maintainer's
process. Your authorship — including any `Co-Authored-By:` trailers — is
preserved on the resulting commit.

There is typically a 1–3 business-day delay between PR acceptance and the
synced commit appearing here. Your PR will be closed with a link to that
commit.

For contribution guidelines, see CONTRIBUTING.md. For
security reports, see [SECURITY.md](SECURITY.md).
